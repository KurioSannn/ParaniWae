# Reference Materials

This folder contains the source material that the product/research team should inspect.

- `PETUNJUK PELAKSANAAN TEKNIS BUDAYA GO! 2026.pdf` - competition Juknis supplied by the user.
- `Lampiran 1 dan 2 Panduan dan Format Penulisan Proposal.docx` - official proposal and product-evidence guidance supplied by the user.
- `BudayaGO_Riset_Pemenang_2025_dan_Ide_2026_2.xlsx` - winner analysis/statistics/ideas/prior-art workbook supplied by the user.
- `TRIA_gitingest.md` - source snapshot for TRIA supplied by the user.

Sensitive administrative attachments (e.g. KTP scans or participant identity forms) were deliberately not copied into this engineering starter pack. Keep them outside source control and only share them when required for the competition's administrative process.

Add raw survey exports, interview notes, partner correspondence, movement reference videos, permission evidence, and partner-approved cultural documents to a restricted `reference-materials/user-evidence/` directory. Do not commit sensitive personal data or unlicensed media to a public repository.
